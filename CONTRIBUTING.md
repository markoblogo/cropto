# Contributing

Cropto accepts focused fixes and improvements that preserve its maintained-prototype status.

1. Open an issue for changes to trading, settlement, wallet, token, or compliance boundaries.
2. Create a branch from `release/demo`.
3. Keep public wording aligned with [PRODUCT_STATUS.md](./PRODUCT_STATUS.md).
4. Run `npm run verify`.
5. Explain user-visible behavior and any remaining operational risk in the pull request.

Never commit credentials, production data, broker messages, or private contract documents.
