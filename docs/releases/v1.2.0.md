# Cropto v1.2.0

Cropto v1.2.0 makes the maintained prototype easier to evaluate, safer to operate, and faster to open.

## Product and documentation

- The public hero now leads with live market data, the partner deck, and feedback.
- The global status message is consistent across English, Ukrainian, Spanish, and Portuguese: production trading is paused while market and demo surfaces remain available.
- The README now gives visitors a product boundary, status table, quick start, visual preview, and direct demo links.
- Crawler files, canonical/social metadata, structured data, licensing, contribution guidance, and a security policy are now included.

## Engineering

- Route-level loading and on-demand locale bundles reduced the main client bundle from 1,118 KB to 254 KB gzip, a 77% reduction.
- All 84 unit tests and four PostgreSQL-backed API integration tests pass.
- CI now uses Node.js 22, starts a clean database, runs the unit suite before server startup, and runs integration tests against the live test server.
- A weekly read-only production verifier checks health, crawler files, canonical metadata, and security headers.
- MapLibre GL, Drizzle ORM, Nodemailer, Express 4, PostCSS, and browser compatibility data were refreshed.
- The previous critical production dependency advisory is removed; `npm audit --omit=dev` now reports eight residual findings, documented in `SECURITY_REPORT.md`.

## Operational notes

- The deployment branch remains `release/demo`.
- The canonical host is `https://cr0pto.com`; the legacy `cropto.abvx.xyz` host remains a redirect boundary.
- The external Last30Days workflow dependency is pinned to a reviewed commit.
- Production trading, clearing, custody, and regulated settlement remain outside this release boundary.
