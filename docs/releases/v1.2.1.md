# Cropto v1.2.1

This patch completes the production dependency hardening left open in v1.2.0 while preserving Cropto's maintained-but-paused product status.

## Changed

- Migrated the server from Express 4 to Express 5.2.1.
- Updated catch-all handling for the Express 5 route syntax.
- Normalized named route parameters before passing them into storage and trading services.
- Replaced the vulnerable npm `xlsx@0.18.5` artifact with the supported official SheetJS 0.20.3 distribution.
- Applied safe transitive updates and pinned Lodash 4.18.1.

## Verification

- TypeScript check and production build pass.
- 85 unit tests pass, including a new XLSX export/import round-trip.
- Four PostgreSQL-backed API integration tests pass on Express 5.
- `npm audit --omit=dev` reports zero vulnerabilities.

The remaining full-audit findings belong to the development-only Hardhat 2 toolchain. That toolchain stays paused with the product's on-chain development and does not ship in the Railway production dependency set.
